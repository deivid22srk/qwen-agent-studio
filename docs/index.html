Qwen Agent Studio

Transforme a interface do Qwen AI em um verdadeiro agente com Tool Calls, acesso a arquivos locais e pasta de projetos — estilo OpenCode / Claude Code.

⬇️ Baixar extensão (.zip) ⭐ Ver no GitHub

Após baixar: extraia → abra chrome://extensions → ative Modo desenvolvedor → Carregar sem compactação → selecione a pasta.

O que ela faz

🛠️

Tool Calls nativos

O Qwen passa a invocar ferramentas reais: ler, escrever, editar, listar e buscar arquivos. Cada chamada é detectada automaticamente nas respostas do modelo, executada e o resultado é devolvido para a conversa continuar.

📁

Pasta de projetos

Selecione uma pasta do seu computador via File System Access API. O agente opera sobre seus arquivos locais — criar hello.py, editar src/index.js, navegar pela árvore do projeto.

🎨

Injeção na UI nativa

Nenhuma interface paralela. Um botão flutuante 🤖 e um painel lateral discretos são injetados diretamente no chat.qwen.ai — preservando todo o resto da experiência.

🔍

Grep + glob

search_files por nome e grep por conteúdo recursivamente. Pede "encontre onde fica a função main" e o agente resolve sozinho, sem copiar e colar código manualmente.

📜

Histórico de tools

Cada chamada é registrada (com argumentos, resultado, duração). Veja exatamente o que o agente fez, na aba Tool Log do painel lateral.

🔒

100% local

Tudo roda dentro do seu navegador. Nenhum dado sai do seu computador, nenhuma telemetria. Os handles de arquivo ficam no IndexedDB do seu perfil.

Como usar

  1. Baixe e extraia a extensão (botão acima).
  2. Abra chrome://extensions no Chrome (ou Edge, Brave, Arc, Opera — qualquer navegador Chromium). Ative o Modo desenvolvedor no canto superior direito.
  3. Clique em Carregar sem compactação e selecione a pasta extraída (qwen-agent-extension).
  4. Abra chat.qwen.ai. Você verá um botão flutuante 🤖 no canto inferior direito.
  5. Clique nele → Selecionar pasta → escolha a pasta do seu projeto.
  6. Ligue o Modo Agente no painel.
  7. No chat do Qwen, peça tarefas como:
    • "liste os arquivos do projeto"
    • "leia o src/index.js e explique"
    • "crie um arquivo test.py que imprime Olá Mundo"
    • "encontre onde fica a função main"
    • "renomeie todas as ocorrências de foo para bar em src/"
💡 Dica: a primeira requisição após ligar o agente pode demorar alguns segundos a mais — o system prompt com a lista de ferramentas é injetado automaticamente. Você verá um badge "⚙️ read_file…" sempre que uma ferramenta estiver em execução.

Ferramentas disponíveis

NomeO que faz
list_filesLista o conteúdo de um diretório
treeMostra a árvore de diretórios
read_fileLê o conteúdo de um arquivo
write_fileCria ou sobrescreve um arquivo
edit_fileEdita trecho exato de um arquivo
append_fileAnexa conteúdo ao final
delete_fileApaga um arquivo
create_directoryCria diretório (recursivo)
search_filesBusca por nome (glob)
grepBusca conteúdo em arquivos
run_commandExecuta shell (requer helper opcional)
finishSinaliza fim da tarefa
